KASO · ART PROMPT PACK

Every image the game can use, with a ready prompt and the exact file name. Images you add replace the built-in drawings; anything still missing keeps the current art, so you can work group by group. Do a whole group (for example all characters) before switching it on, so the look stays consistent.

  1. Pick a style below. Generate the Required image of each character first, then use it as the reference image for its optional expressions.
  2. Save each image with the exact name into the folder shown, inside assets/art/ (for example assets/art/chars/kanor.png).
  3. Run python3 tools/art_manifest.py (add --pixel for pixel art) so the game sees the new files.
  4. Scenes: open Developer Mode → case → EKSENA → 🎯 LAYOUT, tap each clue onto its spot, then EXPORT and save as assets/art/layout.json.
